Frequently asked questions
What is financial scenario planning?

Financial scenario planning is the process of building more than one version of your forecast to see how different decisions or conditions would affect your business. Instead of relying on a single set of numbers, you create what-if scenarios — like a slower sales year or an added hire — and compare the outcomes side by side before you commit.

How is scenario planning different from a regular forecast?

A regular forecast is your single best estimate of what's ahead. Scenario planning builds on that by letting you create and compare alternate versions — best case, worst case, or any specific what-if — so you can see the range of possible outcomes and plan for each one instead of betting on a single projection.

Sync LivePlan to QuickBooks Online or Xero and import your data using the Forecast Builder to quickly create a starting forecast. If you don’t use one of these accounting solutions, LivePlan will guide you through building your forecast manually with step-by-step guidance and examples. Additionally, the AI-Powered LivePlan Assistant will suggest forecast categories you can easily add to your financial forecast. If you need more support, you can access LivePlan services from within the app, including the financial forecasting service here.

Will LivePlan include all the financial statements a bank, lender, or investor would expect to see?

Yes, when you create your financial forecasts in LivePlan the numbers you enter will build these statements automatically. You will end up with a complete income statement, cash flow projections, balance sheet and profit and loss statement.

Can I create pro forma financial statements using LivePlan?

A LivePlan Forecast provides the three standard (or "pro forma") financial statements that accountants and investors generally expect to see. You can create pro forma financial statements easily by connecting LivePlan to QuickBooks Online or Xero. The software will use your actual accounting data to create your starting forecast, which will be used to automatically generate these pro forma statements. You can also enter data manually instead if you don't use one of these accounting tools.

Can I download and print my financial forecasts?

Yes, you can easily download your financial forecast as a PDF or print your forecast. With LivePlan Premium, you can also export your forecast as a .csv file and then import it into Microsoft Excel or Google Sheets.
